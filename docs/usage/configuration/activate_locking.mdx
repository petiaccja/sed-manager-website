# Activating locking

By default, the locking features of your drive are disabled. (The drive is still encrypting your data, but the encryption keys are accessible to anyone, and the data is automatically decrypted when you read it.) When you enable [locking](/docs/theory/the_tcg_spec#locking-and-encryption-features), the device opens up the options to configure users and passwords that limit access to the encrypted data.

When locking is enabled, you can:
- Set up locking ranges
- Enable/disable users and set their passwords
- Give users permissions to access the contents of locking ranges
- Configure MBR shadowing and pre-boot authentication

## The Admin1 authority

When you activate locking, SEDManager asks you to provide a password for the *Admin1* authority. When you later configure the aforementioned features, such as locking ranges, you will have to authenticate as the special Admin1 user.

In case you're the only person using the drive, you can safely reuse the owner password. Make sure you don't lose the Admin1 password though, as that means you can no longer configure the locking features of the drive. Remember that with the owner password, you can always revert the device to factory settings and start over. Just like any password, you can change the Admin1 password at any time too.

:::warning Reverting the drive erases all your data

If you resort to reverting your drive either because you lost your Admin1 password, or you changed your mind about activating locking, be aware that it will erase all of your data. If you don't intend to use locking features, it's best to leave locking inactive.

:::
