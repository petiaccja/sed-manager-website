# Changing passwords

Users can change their passwords by first authenticating with their current password. The usual [limitations](/docs/usage/configuration/edit_users#name-and-password-limitations) about passwords apply.

## Selecting a user

You can select the user whose password you want to change from the dropdown list. The users are displayed prefixed with the [security provider](/docs/theory/the_tcg_spec#security-providers) they reside in.

Furthermore, users are displayed with their names in the specification. You can have a look at this cheat sheet for explanation:

| Name in spec.    | Meaning        |
|------------------|----------------|
| Admin::SID       | Owner          |
| Admin::PSID      | Physical owner |
| Locking::Admin#N | Locking admins |
| Locking::User#N  | Locking users  |

Note that some users may appear in the dropdown list even if they are disabled (e.g. *User#N*) or if their password cannot be changed (e.g. *PSID*). Unfortunately, this is a limitation of the specifications where you cannot query all information about the authorities that could help determine whether you can actually change the password. In case the password is not changeable, you will get an error and nothing will be modified on the device.
