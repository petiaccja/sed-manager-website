# Reverting a device

## Only locking or the entire device

You can either revert just the locking features of the device, or everything on the device:
- **Just the locking features**: All data will be erased from the drive, the locking configuration (i.e. locking ranges, users, permission, shadow MBR) will be reset to its factory defaults, and the locking features will be deactivated. The administrative configuration (i.e. owner password) is unchanged.
- **Entire device**: Both the locking (as described above) and the administrative configuration will be reverted, essentially restoring the device to its original factory state.

:::tip Revert your drive before reselling it

When you resell your drive, revert the entire device. This way, the new owner will be able to use the drive straight away, and your data will be safely deleted. If you haven't enabled locking while you were using the drive, this is a good time to enable locking and erase the global range before reverting it for resale.

:::

## PSID revert

If you know your owner password, you can revert the device by authenticating as the owner. However, if you don't, you can check the device's label for the physical owner's password, typically shown under the *PSID* label. The physical owner's password will allow you to revert the device without the owner's password, but in that case, you must revert the entire device. Once reverted, you can set a new owner's password that you will remember.
